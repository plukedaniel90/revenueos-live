# RevenueOS Live

[Open the live RevenueOS site](https://revenueos-live.danpraneet.chatgpt.site).

RevenueOS explores how market and procurement signals can become usable commercial intelligence. This repository is the public project entry point. The live Site currently holds the application; its source and daily signal pipeline have **not yet been synced to this repository**. Updates on the Site alone do not count as commits here.

Planned public scope: a reproducible demo using synthetic records, documented signal criteria, and dated reports with source links. No employer, customer, or private lead data belongs in public outputs.
